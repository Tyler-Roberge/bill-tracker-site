Privacy Policy

Last updated: September 2026

bill-tracker is a personal automation tool used solely by its owner and developer. It is not distributed to, or usable by, anyone else.

What it accesses

With the owner's explicit OAuth consent, the tool uses the Gmail API to (1) read billing-related emails in the owner's own inbox and (2) send a monthly summary email from the owner's account to the owner's own address. It requests only the gmail.readonly and gmail.send scopes and cannot modify or delete mail.

What happens to the data

Extracted bill amounts are stored in a file on the owner's own computer. No data is transmitted to, stored on, or shared with any third party or external server. There is no analytics, advertising, or tracking of any kind.

Limited Use disclosure

bill-tracker's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
